# Project Statement

**Title:** Student Grading & Performance Analysis System

**Problem:** Basic marks program could produce results; however, continuous manual input and temporary in memory data makes updating and searching records difficult.

**Goal:** To develop a modular Python program from the three subject marks program that will store data, automate result calculation, and perform analysis of class performance.

**Target users:** Students, teachers and academic staff who work with small volumes of academic data.

**Scope:** Three subject marks, total, average, pass/fail status, grades, grade points, ranking, student CRUD operations, search and storage.
